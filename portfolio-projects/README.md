# Data Science Portfolio Projects

This directory contains two Python portfolio projects supporting data exploration, model evaluation, and forecasting:

- [Customer Churn Analysis](./customer-churn-analysis/README.md) — classification pipeline with preprocessing, train/test splitting, model comparison, and classification metrics.
- [Retail Sales Forecasting](./retail-sales-forecasting/README.md) — chronological time-series holdout, seasonal-naive baseline, regression model, MAE, and RMSE.

Both projects require a public dataset to be downloaded separately. Run each workflow locally and review the actual metrics and limitations before reporting results in a resume or interview. No performance numbers are hard-coded into the documentation.
